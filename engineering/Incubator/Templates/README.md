# EKF Templates

## Purpose

This collection contains templates that define repeatable artifact patterns within the Engineering Knowledge Framework.

EKF templates are not created in anticipation of possible use. They are created only after repeated engineering practice reveals a stable pattern worthy of standardization.

## Current Templates

* [Principle](Principle.md)
* [Standard](Standard.md)

## Supporting Guidance

* [Engineering Writing Style Guide](Engineering-Writing-Style-Guide.md)

The Engineering Writing Style Guide supports all EKF artifacts but is not itself a template.

## Admission Rule

A template may be added only when:

1. The artifact type has been used repeatedly.
2. Its structure has remained stable across multiple examples.
3. The structure reduces cognitive load.
4. The template preserves important knowledge without encouraging unnecessary sections.
5. The underlying pattern is consistent with EKF standards and the Constitution.

## Guiding Principle

> Templates are discovered through repetition, not invented through anticipation.
