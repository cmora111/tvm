# Engineering Writing Style Guide

## Status

Incubating

## Voice

EKF writing should be professional, thoughtful, conversational, clear, and technically precise.

## Core Practices

- Write for future engineers.
- Explain why before how.
- Prefer clarity over cleverness.
- Preserve history honestly.
- Keep each artifact focused on one primary question.
- Use timeless language in the Foundation.
- Author in Markdown.

## Formatting Practices

- Use Title Case for major headings.
- Use ISO 8601 dates.
- Use hyphens rather than underscores in names.
- Use zero-padded numbers where sorting matters.
- Use relative Markdown links.
- Use block quotes for declarations and principles.
