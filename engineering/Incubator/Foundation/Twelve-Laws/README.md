# The Twelve Laws of Engineering Knowledge

## Status

Draft

## Purpose

The Twelve Laws will express the fundamental truths that guide how EKF treats engineering knowledge.

## Current Draft Laws

1. Engineering knowledge is a first-class engineering artifact.
2. Preserve the reason, not merely the result.
3. The framework serves the project.
4. Discover before standardizing.
5. Extract abstractions only after they have proven themselves.
6. Every artifact must have a purpose.
7. Knowledge should flow.
8. Engineering should be explainable.
9. Simplicity is a design goal.
10. Preserve history honestly.
11. Every project teaches the framework.
12. Engineering is stewardship.
