# Extraction Checklist

A candidate may be considered for extraction when all answers are **yes**.

- [ ] Does it solve a recurring engineering-knowledge problem?
- [ ] Has it been used in real engineering work?
- [ ] Has it been refined through more than one iteration?
- [ ] Is it independent of a single project?
- [ ] Would another project benefit?
- [ ] Is its purpose clear in one sentence?
- [ ] Does it avoid unnecessary bureaucracy?
- [ ] Has it passed a cooling period and final inspection?
