# Project Templates

## Purpose

This collection contains templates used while engineering the TermForge project.

These templates support recurring project work such as architecture decisions, research, engineering notes, roadmap planning, Forge Sessions, and journal chapters.

## Ownership

These templates belong to TermForge project engineering.

They are not part of the Engineering Knowledge Framework itself and should not graduate with EKF unless repeated use proves that a template is project-independent and broadly reusable.

## Guiding Principle

> Project templates support the work of a project. EKF templates define repeatable engineering-knowledge patterns.
